## Key Implementation Details

### 1. WIB Date API
`GET /api/notes` supports `?date=today|yesterday|YYYY-MM-DD`, defaults to today. POST upserts notes by date using Drizzle's `onConflictDoUpdate`. All date computations use `Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Jakarta' })`.

### 2. Notes UI
Client component with debounced autosave (2s), save button, and "Saved" confirmation badge. Yesterday's notes displayed below as read-only reference. Loading/error states for all API calls. Responsive CSS with mobile breakpoint.

### 3. LLM Summarization
`summarizeNotes(rawText)` calls Deepseek V4 Flash via OpenAI SDK. System prompt instructs categorization into `followUpToday` (urgent/important) and `prepareAhead` (future). Parses JSON response with fallback to line-by-line extraction. 30s timeout, token usage logging.

## Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Date API param style | `?date=today` vs separate endpoints | Single endpoint, query param = flexible and RESTful |
